```bash

# Uses the RSC Flight protocol — a crafted component identifier deserializes into node:child_process.
# Public PoC pattern (lab): 
#   1) hand-craft RSC Flight request (component pings + <identifier> containing node:child_process reference)
#   2) the engine's deserializer executes it on Next.js dev/api

python3 rsc_check.py -h "https://TARGET" --payload 1            # RSC probe (remove before production)
nuclei -u https://TARGET -t http/cves/2025/CVE-2025-55182.yaml
# Note: affects Next.js RSC server-side rendering — there is no simple curl one-liner; use dedicated tooling.
```
