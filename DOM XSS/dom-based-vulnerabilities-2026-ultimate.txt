# ---------------- 16. FALSE-POSITIVE CHECKLIST ----------------
# [ ] string ends in textContent/.innerText/escape()/encodeURIComponent -> NOT XSS
# [ ] jQuery dropped a <script> but handlers onerror DID fire -> that IS xss
# [ ] browser blocked javascript: in location without user gesture -> click-equiv sink, retest with click
# [ ] CSP present blocks injected inline -> report as "executes only with inline-bypass (Angular/JSONP)" if server allows
# [ ] mutation only reproducible in ONE browser -> still valid if that browser is in scope (usually yes)
# [ ] payload escaped server-side as &lt;script...&gt; -> no code exec, don't report
