## Post-exploitation nut-and-bolt list (if you get wp-config)
- `DB_USER / DB_PASSWORD` → login to MySQL box (port 3306)
- `AUTH_KEY`, `SECURE_AUTH_KEY`, `AUTH_SALT` → forge cookies to login as admin WITHOUT password (session hijack)
- Use `AUTH_COOKIE` forgery: value = `username|expiration|hmac(AUTH_KEY)`
