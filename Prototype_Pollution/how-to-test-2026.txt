# HOW TO TEST PROTOTYPE POLLUTION ON A TARGET (2026 expert guide)
# Attacker sets __proto__/constructor.prototype through input; all objects inherit attacker props.

## The N ways to test (client (browser) + server (node) sides)
1. Where input merges copies: JSON body keys __proto__, constructor.prototype.
2. **pollution probe (server)**: body {"__proto__":{"polluted":"yes"}} -> ? (unreachable if not).
3. Object.assign / merge / defaults patterns (lodash(merge,defaultsDeep), jquery.extend(deep)) .
4. Sink drinking polluted props: config.flag, handler.log, options.timeout, BLL options  .
5. Leading to: React template XSS, node RCE (child_process glob match w/ shell), auth bypass
   (isAdmin), SSRF (options.url read), DoS (object.size), CSRF token bypass.
6. Client-side: chrome flag in source mapping custom object prototype = taint visible.
7. URL-encoded key smuggling / query-only merges that stringify "__proto__".

## Step-by-step on target
1. Enumerate merge surface: JSON body to /api/set, query hash merge, JSON-import endpoints, config-save.
2. Send the canonical probe and look for the artifact in responses/behavior:
   body:  { "__proto__": { "x": 1 } }   -> then any getPrototype-echo (JSON.stringify of an object shows x).
3. If node backend: send {"__proto__":{"polluted":"yes"}} and check a public object (e.g., user object JSON).
4. If it lands, chain to a sink you can OBSERVE (config.flag=yes changes a response; timeout=0 kills).
5. For RCE test: only on YOUR lab:
   // app.js: const execSync = require('child_process');
   // if code uses Object.assign({},req.body,config) check shell:"/bin/sh" or constructor.prototype env:

## Verify & false positives
- Polluted only in the REQUEST copy but not stored/global = not a vuln until global inheritance shown.
- If the library json-parses but does NOT merge to Object.prototype (some JSON.parse), you only proved
  parsing (a copy) - report only global "polluted" proof: any object later containing the key.
# test batch for global proof:
#   1) probe set  __proto__:{zz:1}
#   2) request a DIFFERENT untainted object that JSON-stringifies zz -> if shown, global pollution.
